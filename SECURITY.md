# Security reporting

Report vulnerabilities privately through **GitHub private vulnerability reporting** for this repository. Do not include captured content, credentials, or personal data in a public issue. The maintainer must enable this reporting feature before publication; until then, there is no approved private reporting route and the repository is not ready for public release.

Captured content can retain unexpected sensitive values. Treat every `.agentdbg` store as private and review it before sharing. The Docker worker limits accidental effects; it is not a hostile-code sandbox. Windows storage ACL protection has not been verified.
